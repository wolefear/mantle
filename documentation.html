What it is

Mantle Seeker is an AI research agent for tokenized asset distribution. Issuance is largely solved; the hard problem is distribution — reaching the right holders, in the right regions, through the right venues. Seeker investigates that problem before it recommends anything.

It is built as a static frontend (HTML5 / CSS3 / vanilla JavaScript) with a set of Netlify Functions that host the research orchestrator. The same agent brain also runs entirely client-side as a fallback, so the product works even on a purely static host.

Trust principles

  • Never answer immediately. Every run investigates first, then reasons, then concludes.
  • Evidence, reasoning, confidence. Every conclusion carries all three.
  • No fabrication. No invented statistics, no fake citations, no imaginary comparables.
  • Label the source. Findings from Mantle Skills are marked as evidence; the agent's inferences are marked as reasoning / recommendations.
  • Explain uncertainty. Confidence is scored on evidence sufficiency and stated plainly.

Architecture

Three layers, cleanly separated:

frontend/ static UI (this site) index / research / live / report / documentation assets/app.js UI logic + interview + live progress assets/agent.js client-side research brain (fallback) netlify/functions/ backend research service research.js POST /api/research (buffered) research-stream.js POST /api/research/stream (SSE) lib/orchestrator.js investigation loop lib/skills.js Mantle Skills adapters lib/engines.js scoring / evidence / reasoning lib/util.js normalize + shared helpers

The frontend calls the backend first; if the endpoint is unavailable (for example on a static-only deploy) it transparently falls back to the in-browser agent, so a demo never breaks.

Orchestration loop

The orchestrator runs a disciplined, institutional workflow rather than a single prompt:

  1. Intake & normalize the brief (canonical + legacy field names).
  2. Plan which skills the question actually requires.
  3. Investigate — invoke each skill and record findings as evidence (E-001…).
  4. Score readiness, liquidity, reach, ecosystem and risk.
  5. Reason over evidence, surface conflicts and gaps.
  6. Measure confidence from evidence sufficiency.
  7. Compile the Distribution Intelligence Dossier.
  8. Log the full activity trail for replay.

Every stage is emitted as an event, which is what drives the live investigation screen and Research Replay Mode.

Mantle Skills

Data Indexer

Finds comparable RWAs and indexes on-chain distribution data.

Risk Evaluator

Assesses liquidity, concentration and regulatory risk.

DeFi Operator

Maps venues, liquidity routes and cross-chain pathways.

Network Primer

Grounds the analysis in Mantle ecosystem context.

Skills are invoked through lib/skills.js, which can call a live Mantle Skills endpoint (MANTLE_SKILLS_URL) or run deterministic local adapters for offline demos.

API endpoints

POST /api/research

Runs a full investigation and returns the complete result in one response.

POST /api/research Content-Type: application/json { "assetName": "Helios Solar Yield Note", "assetType": "Treasury", "assetValue": "$25,000,000", "targetInvestors": "Institution", "targetRegion": "Europe", "launchStage": "Pre-Issuance", "distributionGoal": "broaden holder base" } => { ok, session, activityLog, skillRuns, dossier }

POST /api/research/stream

Server-Sent Events stream emitting session, event, plan, skill, error and done messages as the investigation progresses.

Data model

A run produces a single dossier object. Key fields:

dossier = { researchId, status, asset{...}, objective, plan{ skills[], considered }, summary{ text }, readiness{...}, scores{ readiness, liquidity, reach, eco, riskScore, ... }, evidence[ { id, source, finding, importance, confidence, confidencePct, timestamp } ], reasoning[], conflicts[], liquidity{...}, opportunities{...}, risks[ {type,severity,...} ], crosschain{...}, strategy[], recommendations, gaps[], confidence{ value, label, explanation, factors }, nextActions[], session{...}, activityLog[], skillRuns[] }

Distribution Intelligence Dossier

report.html presents the run as an institutional intelligence file rather than a chat reply. It is pure HTML/CSS/vanilla JS (no chart libraries) and renders from the live backend dossier or the offline engine identically.

Hero gauge

Run & deploy

# local static preview python3 -m http.server 8000 # full stack (functions) with Netlify CLI netlify dev # deploy netlify deploy --prod

Environment variables: AI_API_KEY, MANTLE_SKILLS_URL, plus MANTLE_FORCE_FAIL and MANTLE_SKILL_DELAY_MS for testing failure and latency handling. With none set, the agent runs fully offline using its local engines.
